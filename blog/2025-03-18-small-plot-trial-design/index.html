Designing small-plot trials that still yield clean data

Student and early-career trials rarely have dozens of replicates. Good design still separates genetic signal from field noise.

Basics that help

  • Randomise entries within blocks; avoid always putting the same check on the edge
  • Use border rows where resources allow
  • Keep plot size practical for hand operations but large enough for meaningful yield samples
  • Record missing plants and obvious field gradients (shade, low spots)

Simple R scripts can randomise layouts and later analyse RCBD or augmented designs. Start with a clear field map before sowing — most analysis problems begin with unclear plot labels.
